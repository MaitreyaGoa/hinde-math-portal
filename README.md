# 🎓 Hinde Classes – Math Game Portal

Interactive math game portal with 3 games covering Percentages, Ratios, and Averages.

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | **Main portal homepage** — navigate to all games from here |
| `percentage-quest.html` | 🎯 Percentage Quest game |
| `ratio-quest.html` | ⚖️ Ratio Quest game |
| `average-arena.html` | 📊 Average Arena game |

## 🚀 Deploy to GitHub Pages

1. Create repo `hinde-math-portal`
2. Upload all 4 HTML files
3. **Settings → Pages → Deploy from branch → main → / (root)** → Save
4. Live at: `https://YOUR-USERNAME.github.io/hinde-math-portal/`

## ✨ Features
- Hinde Classes logo + branding on every page
- Home navigation from every game page
- Footer: "Developed by Maitreya Hinde | 7358425108"
- 3 games × 5 levels × randomized questions
- Progress saved per-game via localStorage
